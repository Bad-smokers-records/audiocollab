# Screenshot

Metti qui le immagini referenziate dal tag `<screenshot>` in `appinfo/info.xml`.

- `dashboard.png` — screenshot della dashboard (con l'avatar in alto a destra nascosto, come da anteprima già verificata).

L'URL in `info.xml` punta a `raw.githubusercontent.com/<org>/<repo>/main/screenshots/dashboard.png`: funziona solo dopo che il repository è stato pushato su GitHub con questo file al suo interno.
